# 2026-10-21 — Map clusters and full window in the WCAG mapping

Added two rows to the WCAG 2.2 mapping: a map cluster is a named button operated with Enter and Space whose focus is not lost when it splits, and a full-window map is a named modal dialog that Escape closes and returns focus from.
