# 2026-10-19 — Maps

Added standards for maps in Marin products: when to use one, rules for location data (coordinates are optional, never guessed, and validated), basemap choice and attribution, one marker style, grouping of shared locations, counts of mapped and unmapped records, scrolling and touch behavior, and privacy. Added accessibility requirements for maps, a text alternative, and testing. Noted that a map tile host is an allowed external integration and a documented content security policy addition.

Affected standards:

- `product-design/maps.md` (new)
- `product-design/README.md`
- `product-design/runtime-dependencies.md`
- `accessibility/maps.md` (new)
- `accessibility/README.md`
- `accessibility/testing.md`
- `accessibility/wcag-2.2-mapping.md`
- `security/standard.md`
- `README.md`

First implementation is the Map view in `marin-reach` (see its `docs/decisions.md`). The workflow that applies the standard is the `map-views` skill in `marin-skills`.
