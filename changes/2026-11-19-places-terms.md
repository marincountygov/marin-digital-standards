# 2026-11-19 — Names for places, facilities and events

Added a short list of names for places to the terminology page: Place, District, City or town, Community, Facility, Venue and Event. It says what each means, how it is written, and what its group is called.

- A district is written "District 3".
- Communities are called "Communities".
- A filter on territory is named "Place", and a field that takes a place or a facility is named "Place or facility".
- A list of where events are held is named "Venues".
- "Location" is not used for a territory or a venue. A point on a map is a "map point".

Affected standards:

- `content-design/terminology.md`

Implementation: Marin Data keeps the names (`organizations/place-kinds.json`). Marin Mentions, Marin Reach, Marin Links and Marin Docs follow it.
