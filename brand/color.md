# Color

Use the County palette from the published Identity Style Guide as the controlling visual reference. When exact values are needed, use the values below, the official guide, or a supplied brand file — never estimate from a screenshot.

## Palette and permitted uses

| Color | HEX | Background with white text | Background with black text | Usable as font color |
|---|---:|:---:|:---:|:---:|
| Blue | `#0777cf` | Yes | Yes | Yes |
| Dark Gray | `#6f6f6f` | Yes | No | Yes |
| Light Gray | `#a9a9a9` | No | Yes | No |
| Red | `#b45340` | Yes | No | Yes |
| Green | `#73784a` | Yes | Yes | Yes |
| Brown | `#a2662b` | Yes | Yes | Yes |
| Black | `#000000` | Yes | No | Yes |
| Gold | `#e5b53b` | No | Yes | No |

Never pair white text on Light Gray or Gold. Never pair black text on Dark Gray, Red, or Black.

Light Gray and Gold are never used as font/text colors — only as backgrounds.

## How to apply color

- Use palette colors for identity, structure, emphasis, and wayfinding — not decoration.
- Prefer restrained accent use; avoid arbitrary non-palette colors unless the asset has a documented campaign or program-specific palette.
- When using a palette color as a font color, use it for headings, labels, links, or short emphasis — not for large blocks of colored body copy.
- Color supports meaning; it's never the only way meaning is expressed (see `marin-digital-standards/accessibility/color-and-contrast.md` — that's the accessibility requirement this visual rule pairs with, not a substitute for it).

## Charts and diagrams

Use County palette colors when feasible, the fewest colors needed to distinguish categories, and the permitted font/background pairings above. Label directly where practical. Avoid heavy gradients, 3D effects, texture fills, and decorative chartjunk. Make the main takeaway visually prominent, not just present.
