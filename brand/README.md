# Brand

Marin's visual identity rules — the source of truth for what the County brand *is*, distinct from how it's implemented as reusable interface tokens (that's `marin-ui/tokens`).

## Scope

- Identity principles
- Official County colors
- Approved typefaces
- Logo usage
- Imagery rules

## Planned files

- `identity.md`
- `color.md`
- `typography.md`
- `logo.md`
- `imagery.md`

Not yet populated — content is being migrated incrementally from `marinskills/brand-standards` and the branding sections of `marinappsbrand/SPEC.md`.

Note the distinction from `marin-ui/tokens`: this domain defines the official colors (e.g. Marin blue is `#0777cf`); `marin-ui` defines what that becomes as a semantic interface token (e.g. `--app-accent`) and how components consume it.
